# K2 — прокат квадроциклов и эндуро в Туле

Трёхстраничный статический сайт без сборки, npm и серверных зависимостей.

- `index.html` — главная, техника, маршрут, анимированные карточки, FAQ.
- `rental.html` — техника, тарифы, условия и порядок записи.
- `contacts.html` — о компании, контакты, фотогалерея с полноэкранным просмотром.

## Запуск

Откройте `index.html` или выполните `python3 -m http.server 8080` в папке проекта.
Для GitHub Pages выберите Settings → Pages → Deploy from a branch → `main` / `(root)`.
Все ссылки относительные: сайт работает и в подпапке `/Prokat-Tyla/`.

## Дизайн

Главная (`index.html`) перенесена на оригинальную вёрстку страницы аренды kaARAss/Bull-bike: полноэкранный фон, прозрачная фиксированная шапка, контент снизу слева, печатающийся заголовок Russo One, оранжевые кнопки, Oswald в заголовках секций, карточки форматов и неоновые границы, горизонтальная галерея и мягкие 3D-эффекты. Исходная каскадная таблица стилей сохранена в `assets/rental-home.css`, адаптер K2 — `assets/rental-home-k2.css`, интерактивность — `assets/rental-home.js`. Шрифты локальные, включая встроенные в CSS Oswald и Russo One с лицензиями OFL.

Контент, фотографии, контакты и тарифы заменены на K2. Услуги, которых нет у K2, чужие отзывы, рейтинги, гарантии и контактные данные не перенесены. Страницы `rental.html` и `contacts.html` сохранены в прежнем дизайне; этот этап меняет только главную. Исходные репозитории не изменяются.

После получения отзывов можно заменить содержимое `.float-card`, сохранив анимацию. Фотография эндуро также взята из альбома K2.

## Приватность и доступность

Шрифты и фотографии локальные. Нет аналитики, сторонних скриптов, cookies, сбора телефонов, секретов и токенов. Внешние сервисы открываются только по ссылкам. Есть reduced-motion, клавиатурная навигация, Escape и стрелки в галерее, focus states, alt у фотографий, адаптация для мобильных устройств. Шрифты Google Fonts Manrope и Unbounded: SIL Open Font License, тексты лицензий в `assets/fonts/`.

## Проверка

Все три страницы проверены при ширинах 1440, 390 и 320 px: нет горизонтального переполнения, ошибок JavaScript и не загрузившихся изображений. Проверены мобильное меню, FAQ, просмотр фотографий, Escape и стрелки. Анимация карточек работает и отключается при prefers-reduced-motion. Отчёт: QA.json.

В архиве фото сохранено 1225 из 1226 изображений альбома. Одна фотография недоступна на стороне ВК (HTTP 404); ссылка есть в unavailable.json фотoархива.

### Баннер главной

На первом экране используется оригинальная обложка K2 из сообщества ВК — без рамки и элементов интерфейса присланного скриншота. На компьютере сохраняется весь баннер; на телефоне кадр сфокусирован на райдерах. Для загрузки через MCP с ограничением размера запроса изображение оптимизировано и разделено на шесть бесшовных SVG-фрагментов со встроенным WebP. Они отображаются одной сеткой без промежутков. Остальные фотографии и страницы не менялись.
