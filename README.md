# K2 — прокат квадроциклов и эндуро в Туле

Трёхстраничный статический сайт без сборки, npm и серверных зависимостей.

- `index.html` — главная, техника, маршрут, анимированные карточки, FAQ.
- `rental.html` — техника, тарифы, условия и порядок записи.
- `contacts.html` — о компании, контакты, фотогалерея с полноэкранным просмотром.

## Запуск

Откройте `index.html` или выполните `python3 -m http.server 8080` в папке проекта.
Для GitHub Pages выберите Settings → Pages → Deploy from a branch → `main` / `(root)`.
Все ссылки относительные: сайт работает и в подпапке `/Prokat-Tyla/`.

## Дизайн

Главная возвращена к первоначальной структуре K2 (коммит `53bbabaeae5288c7603becf116125c30b14400b1`). Все блоки после первого экрана, их порядок, содержимое и оформление сохранены из этой версии: бегущая строка, техника, маршрут, парящие преимущества, фотографии, FAQ, CTA и подвал. Используются исходные `assets/site.css` и `assets/site.js`.

Изменён только первый экран: оригинальный баннер K2 заполняет всю площадь экрана с сохранением пропорций и кадрированием, поверх — печатающийся заголовок и кнопки «Записаться» и «Услуги и цены». Шапка сохраняет первоначальные логотип, навигацию и оформление, но лежит поверх баннера и получает тёмный фон при прокрутке. Изолированные стили и эффект: `assets/home-hero.css`, `assets/home-hero.js`. Полная копия структуры Bull-bike больше не используется. Две остальные страницы не изменены.

## Контент и ограничения

Источник: https://vk.ru/k2renttula, альбом https://vk.ru/album-238016439_311159436. Дата получения: 28.10.2026.

Прайс из описания сообщества: 1 час — 5500 ₽, 1,5 часа — 8000 ₽, 2,5 часа — 12000 ₽. Привязка цены к типу техники и пассажиру в описании не уточнена — на сайте это явно оговорено. Перед коммерческим запуском подтвердите цены, возрастные ограничения, требования к документам и страхованию у компании.

Фотографии в `assets/img/` — реальные кадры K2, выбранные для сайта; происхождение указано в `content/photos.json`. Архив всего доступного альбома поставляется отдельно, чтобы не утяжелять сайт. Права на публикацию материалов и согласия изображённых людей необходимо подтвердить у владельца компании.

**Отзывы не выдуманы и не скопированы у другой компании.** Достоверные отзывы K2 пока не получены. Вместо них использован парящий блок преимуществ и ссылка на сообщество. После получения отзывов можно заменить содержимое `.float-card`, сохранив анимацию. Фотография эндуро также взята из альбома K2.

Кнопки записи ведут в сообщения K2: https://vk.me/k2renttula. Это не форма и не автоматическое подтверждение бронирования. Телефон: +7 919 089-15-99. Адрес: Тула, Мелиоративная, 7с1. Карта открывается по адресу в новом окне, точная точка не выдумана.

## Приватность и доступность

Шрифты и фотографии локальные. Нет аналитики, сторонних скриптов, cookies, сбора телефонов, секретов и токенов. Внешние сервисы открываются только по ссылкам. Есть reduced-motion, клавиатурная навигация, Escape и стрелки в галерее, focus states, alt у фотографий, адаптация для мобильных устройств. Шрифты Google Fonts Manrope и Unbounded: SIL Open Font License, тексты лицензий в `assets/fonts/`.

## Проверка

Все три страницы проверены при ширинах 1440, 390 и 320 px: нет горизонтального переполнения, ошибок JavaScript и не загрузившихся изображений. Проверены мобильное меню, FAQ, просмотр фотографий, Escape и стрелки. Анимация карточек работает и отключается при prefers-reduced-motion. Отчёт: QA.json.

В архиве фото сохранено 1225 из 1226 изображений альбома. Одна фотография недоступна на стороне ВК (HTTP 404); ссылка есть в unavailable.json фотoархива.

### Баннер главной

На первом экране используется оригинальная обложка K2 из сообщества ВК — без рамки и элементов интерфейса присланного скриншота. Баннер заполняет весь первый экран без растягивания; кадрирование сфокусировано на райдерах и технике. Для загрузки через MCP с ограничением размера запроса изображение оптимизировано и разделено на шесть бесшовных SVG-фрагментов со встроенным WebP. Они отображаются одной сеткой без промежутков. Остальные фотографии и страницы не менялись.
